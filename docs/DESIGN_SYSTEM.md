# Design System

## Visual direction

The app should feel:
- modern
- trustworthy
- clean
- editorial
- mobile-first

Avoid:
- overly playful UI
- excessive gradients
- heavy shadows
- social-network-like visual clutter

## Colors

## UI principles

- Use generous spacing.
- Prefer rounded corners around 10–12px.
- Keep article cards simple and readable.
- Use strong visual hierarchy.
- Prioritize readability over decoration.
